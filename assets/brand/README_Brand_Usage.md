# Cartary brand kit

Tagline: **Your world, mapped.**

## Identity

- Navy: `#172F44` — primary brand background and headings
- Cloud: `#F4F7F8` — light-mode application background
- Sky: `#83B9D2` — route / geographic illustration and secondary UI
- Orange: `#EE9862` — EXACT brand accent and app-icon pin fill
- White: `#FFFFFF` — cards and elevated light surfaces
- Dark cards: `#234359` — suggested raised surface over navy

## Type

Use the iOS system font (SF Pro Display for branding/headings, SF Pro Text for body). Rendered marketing PNGs substitute Inter Display and Inter. Font files are not included.

## Production rules

- Use the folded map and single orange location pin as the signature mark. No logo text inside the app icon. The app icon is an unmasked full square; iOS adds rounded corners.
- Topographic contours are reserved for hero surfaces, splash/onboarding, web and social. Do not repeat them beneath map, cards or controls.
- Use Cloud canvas and white cards in light mode; thin borders separate the two (their color contrast is only ~1.08:1). Use navy backgrounds and lighter navy cards in dark mode.
- Navy on Cloud provides approximately 12.8:1 text contrast. Orange on Cloud provides only 2.1:1, so avoid orange as small text or the sole indicator of interactive state. Give orange pins a strong silhouette and use navy outlines where needed.
- Positioning: a native personal map library for imported Google My Maps collections. Do not imply live sync, shared editing, or multi-stop routing ships in v1.

## Deliverable sizes

- App icon PNG: 1024 x 1024 px.
- Light wordmark PNG: 2400 x 800 px on white.
- Dark wordmark PNG: 2400 x 800 px on `#172F44`.
- Hero topographic background PNG: 1200 x 630 px on Cloud.
- Brand guide: US Letter, 1-page PDF (with a PNG preview).
- Editable SVG sources included for the icon, mark and contour background.
